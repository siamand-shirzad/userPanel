# User Panel

Dashboard layout (header, sidebar, routed content) with full CRUD on users and posts against a REST API, comments, gallery and tasks pages, and dark mode.

پنل کاربری با CRUD کاربران و پست‌ها و حالت تاریک.

## Stack
React · React Router · axios · Tailwind CSS

## Run
```bash
npm install
npm run dev
```
